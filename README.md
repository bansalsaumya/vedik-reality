## 🚀 Key Features

### 🏢 Public Discovery Experience
1. **Full-Screen Auto Hero Image Slider**:
   - 4.5-second auto-advancing slideshow featuring luxury residential estates, private villas, high-rise apartments, and commercial hubs.
   - Smooth crossfade & Ken Burns zoom animation.
   - Integrated floating **Property Search Panel**.

2. **Smart Property Filtering & Discovery**:
   - Filter by **Location Corridor** (*Golf Course Road, Golf Course Extension, SPR, Dwarka Expressway, Noida Expressway*).
   - Filter by **Asset Type** (*Luxury Apartment, Independent Villa, Grade-A Commercial, Villa Plot*).
   - Filter by **BHK Configuration** (*3 BHK, 4 BHK, 5 BHK / Duplex Penthouse*), Budget range, and Status.
   - Instant sorting (*Price Low-to-High, High-to-Low, Newest, Most Viewed*).

3. **Property Detail Experience**:
   - Multi-photo image gallery lightbox.
   - Specs summary grid (*BHK, Super Area, Developer Name, Status*).
   - Verified **RERA ID** badges.
   - World-class amenities grid with custom icons.
   - **Sticky Lead Capture Form** + direct WhatsApp & Call triggers.

4. **10 Key Homepage Sections**:
   - Auto Hero Slider & Floating Filter
   - Featured Properties Grid
   - Featured Real Estate Projects & Mega Townships
   - The Vedik Advantage (6 Core Pillars)
   - Property Categories
   - Prime Location Hubs
   - Real Estate Advisory Services
   - Verified Client Testimonials
   - High-Impact Lead Banner & Contact Desk
   - Comprehensive Corporate Footer

### 🛡️ Protected Admin Portal & CRM Dashboard (`/admin`)

- **Secure JWT Authentication**: Protected admin access (`/admin/login`).
- **Live Metrics Overview**:
  - Total Properties, Active Listings, Total Enquiries.
  - New Unread Leads, WhatsApp Click Tracking, and Most Viewed Properties.
- **Lead Pipeline CRM**:
  - View client inquiries with source tracking (*Hero CTA, Property Page, Contact Form, WhatsApp*).
  - Update lead status pipeline (*NEW*, *CONTACTED*, *INTERESTED*, *FOLLOW-UP*, *CONVERTED*, *NOT INTERESTED*).
- **Full Property CRUD**:
  - Add, edit, publish/unpublish, mark Available/Sold Out, toggle Featured status, and edit RERA info.
- **Website Settings Manager**:
  - Update business phone number, WhatsApp number, office address, and social media links directly without code changes.

## 💻 Local Setup & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/vedik-reality.git
   cd vedik-reality
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Full-Stack Dev Server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   - Website: `http://localhost:5173/`
   - Admin Login: `http://localhost:5173/admin/login`
   - **Default Admin Email**: `admin@vedikreality.com`
   - **Default Password**: `admin123`
